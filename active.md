## global · Every project

- global/close-against-the-standing-goal: Do: Before wrapping up, re-read the session's original goal and name its next unbuilt piece and the installed tool that fits it; propose that, not only the finished request. Not: Declare the work done because the latest request is met while the original goal has an obvious next step.
- global/live-by-default-not-approval-queues: Do: When a system learns something from the user, make it take effect at once and keep it easy to see and veto; batch what needs a decision. Not: Gate each learned item on a separate approval from the user. Because: Having to approve each rule is exhausting and not optimal.
